# オーグリードvsドワチャッカ

オーグリード大陸とドワチャッカ大陸のふくびき景品（1等〜3等）の期待値を比較・判定します。

## 概要
- オーグリード大陸の1等・2等・3等コインの「7日間平均価格」を定期的に自動取得し、どちらの大陸でふくびきを引くのが効率的かを判定します。
- ドワチャッカ大陸の景品価格は固定値（1等: 297,000G / 2等: 150,000G / 3等: 80,000G）として計算しています。

## 計算式
- **期待値の和**: `0.16x + 0.24y + 0.32z`
- **判定式**: `x + 1.5y + 2z > 682,000`
  （上記を満たす場合、オーグリード大陸が有利と判定）

## データ引用元
オーグリード大陸のコイン相場データは、[DQX相場情報サイト](https://dqx-souba.game-blog.app)の数値を引用しています。
